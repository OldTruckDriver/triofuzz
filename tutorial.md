# Tutorial: Extending TrioFuzz with Custom Learning Algorithms

This tutorial explains how to implement a custom learning algorithm for TrioFuzz using the **Pluggable Learning Module** interface. The module is defined by two methods — `generateWorkerTask()` and `processResult()` — which together form a closed-loop learning cycle that can be replaced without modifying any other part of the engine.

## Overview

TrioFuzz's scheduler thread runs a simple loop:

```
while (running) {
    // 1. Collect execution results from workers
    results = resultQueues.swapAndGet()
    for (result in results):
        learner.processResult(pendingTasks[result.id], result.found_new_coverage)

    // 2. Generate new tasks for workers
    for each worker queue that needs tasks:
        task = learner.generateWorkerTask()
        enqueue(task)
}
```

The learning algorithm is fully encapsulated behind two methods:

| Method | Called by | Purpose |
|---|---|---|
| `generateWorkerTask()` | Scheduler thread | Decide **what** to fuzz: which configuration, which operators, and in what order |
| `processResult(task, found)` | Scheduler thread | Learn from the outcome: update internal model based on whether the task found new coverage |

By implementing a class with these two methods, you can plug in any learning algorithm — bandit, evolutionary, reinforcement learning, or a simple baseline — without touching the thread engine, execution logic, or coverage tracking.

## The Task Interface

Both methods communicate through the `TrioFuzzUnifiedLearner::Task` struct:

```cpp
struct Task {
    size_t config_arm;                    // Configuration index (Layer 1 decision)
    std::string power_schedule;           // Seed scheduling: "fast", "explore", "coe", "ecofuzz"
    bool use_mopt;                        // true = MOpt operators, false = Havoc operators
    bool splice_enabled;                  // Whether to include splice operators
    bool use_analysis;                    // Use analysis algorithms (CmpLog, Redqueen, etc.)
    std::vector<size_t> operator_sequence; // Ordered list of operator indices to apply
    size_t stack_size;                    // Number of operators in the sequence
    bool is_exploration;                  // true if generated by explorer thread
};
```

**`generateWorkerTask()`** fills these fields to describe a complete mutation strategy. **`processResult(task, found_new_coverage)`** receives the same Task back along with a boolean indicating whether the execution discovered new coverage.

## Step-by-Step: Implementing a Custom Learner

### Step 1: Define Your Learner Class

Create a new header file (e.g., `include/core/my_custom_learner.hpp`):

```cpp
#pragma once

#include <vector>
#include <random>
#include <atomic>
#include <thread>
#include "core/triofuzz_unified_learner.hpp"  // For Task struct and TrioFuzzConfigArm

namespace triofuzz {

class MyCustomLearner {
public:
    // Re-use the same Task type
    using Task = TrioFuzzUnifiedLearner::Task;

    explicit MyCustomLearner(size_t num_havoc_ops = 35, size_t num_mopt_ops = 19)
        : num_havoc_ops_(num_havoc_ops), num_mopt_ops_(num_mopt_ops) {
        // Initialize your learning state here
        arms_ = getTrioFuzzConfigArms(/*enable_ecofuzz=*/true);
    }

    /**
     * Generate a task for a worker thread.
     * This is where your learning algorithm makes decisions.
     */
    Task generateWorkerTask(bool allow_analysis = true) {
        ensureRng();
        Task task;
        task.is_exploration = false;
        task.use_analysis = false;

        // --- YOUR DECISION LOGIC HERE ---
        // Select which configuration arm to use
        size_t arm_idx = selectArm(allow_analysis);
        const auto& arm = arms_[arm_idx];
        task.config_arm = arm_idx;
        task.power_schedule = arm.power_schedule;
        task.use_mopt = arm.use_mopt;
        task.splice_enabled = arm.splice_enabled;
        task.use_analysis = arm.use_analysis;

        // Generate operator sequence
        if (task.use_analysis) {
            task.stack_size = 1;
            task.operator_sequence = {selectAnalysisOp()};
        } else {
            task.stack_size = selectStackSize();
            size_t num_ops = task.use_mopt ? num_mopt_ops_ : num_havoc_ops_;
            task.operator_sequence = generateSequence(task.stack_size, num_ops);
        }

        return task;
    }

    /**
     * Generate a random exploration task for explorer threads.
     */
    Task generateExplorerTask() {
        ensureRng();
        Task task;
        task.is_exploration = true;
        // Explorers use uniform random selection (no learning)
        size_t arm_idx = std::uniform_int_distribution<size_t>(0, arms_.size() - 1)(rng_);
        const auto& arm = arms_[arm_idx];
        task.config_arm = arm_idx;
        task.power_schedule = arm.power_schedule;
        task.use_mopt = arm.use_mopt;
        task.splice_enabled = arm.splice_enabled;
        task.use_analysis = arm.use_analysis;

        task.stack_size = selectStackSize();
        size_t num_ops = task.use_mopt ? num_mopt_ops_ : num_havoc_ops_;
        task.operator_sequence = generateSequence(task.stack_size, num_ops);
        return task;
    }

    /**
     * Process execution result and update your learning model.
     * Called by the scheduler thread after a worker reports back.
     *
     * @param task   The task that was executed (same object from generateWorkerTask)
     * @param found  true if the execution discovered new coverage
     */
    void processResult(const Task& task, bool found_new_coverage) {
        // --- YOUR UPDATE LOGIC HERE ---
        updateModel(task.config_arm, task.operator_sequence, found_new_coverage);
    }

private:
    std::vector<TrioFuzzConfigArm> arms_;
    size_t num_havoc_ops_;
    size_t num_mopt_ops_;

    // --- Your learning state ---
    // e.g., reward counters, weight vectors, Q-tables, neural network, etc.

    size_t selectArm(bool allow_analysis) {
        // Your arm selection logic
        // Example: uniform random (baseline)
        return std::uniform_int_distribution<size_t>(0, arms_.size() - 1)(rng_);
    }

    size_t selectAnalysisOp() {
        return std::uniform_int_distribution<size_t>(0, 5)(rng_);
    }

    size_t selectStackSize() {
        // AFL++ havoc style: 1 << (1 + rand_below(4))
        return 1UL << (1UL + std::uniform_int_distribution<uint32_t>(0, 3)(rng_));
    }

    std::vector<size_t> generateSequence(size_t len, size_t num_ops) {
        std::vector<size_t> seq(len);
        std::uniform_int_distribution<size_t> dist(0, num_ops - 1);
        for (auto& s : seq) s = dist(rng_);
        return seq;
    }

    void updateModel(size_t arm, const std::vector<size_t>& ops, bool found) {
        // Your learning update
        // Example: increment success/failure counters for the selected arm
    }

    static thread_local std::mt19937 rng_;
    static thread_local bool rng_init_;
    static void ensureRng() {
        if (!rng_init_) {
            std::random_device rd;
            rng_.seed(rd() ^ std::hash<std::thread::id>{}(std::this_thread::get_id()));
            rng_init_ = true;
        }
    }
};

inline thread_local std::mt19937 MyCustomLearner::rng_;
inline thread_local bool MyCustomLearner::rng_init_ = false;

} // namespace triofuzz
```

### Step 2: Integrate into the Thread Engine

In `include/core/specialized_thread_engine.hpp`, add your learner as an alternative to `TrioFuzzUnifiedLearner`:

```cpp
#include "core/my_custom_learner.hpp"

// Inside the SpecializedThreadEngine class, add:
std::unique_ptr<triofuzz::MyCustomLearner> custom_learner_;
```

In `src/core/specialized_thread_engine.cpp`, in the constructor where the learner is initialized (look for `triofuzz_learner_ = std::make_unique<...>`), add a conditional branch:

```cpp
if (config_.use_custom_learner) {
    custom_learner_ = std::make_unique<triofuzz::MyCustomLearner>(
        /* num_havoc_ops */ 35, /* num_mopt_ops */ 19);
} else if (config_.use_triofuzz_unified) {
    triofuzz_learner_ = std::make_unique<triofuzz::TrioFuzzUnifiedLearner>(trio_cfg);
}
```

Then in `schedulerThreadTrioFuzz()`, replace the learner calls:

```cpp
// Task generation — replace:
//   auto task_info = triofuzz_learner_->generateWorkerTask(...);
// with:
auto task_info = custom_learner_
    ? custom_learner_->generateWorkerTask(allow_analysis)
    : triofuzz_learner_->generateWorkerTask(allow_analysis);

// Result processing — replace:
//   triofuzz_learner_->processResult(it->second, result.found_new_coverage);
// with:
if (custom_learner_)
    custom_learner_->processResult(it->second, result.found_new_coverage);
else
    triofuzz_learner_->processResult(it->second, result.found_new_coverage);
```

### Step 3: Add a Configuration Flag

In `include/core/engine.hpp`, add a new flag to `FuzzingConfig`:

```cpp
bool use_custom_learner = false;  // Enable custom learning algorithm
```

In `src/interface/triofuzz_main.cpp`, add the CLI argument:

```cpp
// In the argument parsing section, add:
if (arg == "--use-custom-learner") {
    config.use_custom_learner = true;
}
```

### Step 4: Build and Run

```bash
mkdir build && cd build
cmake -DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++ ..
make -j$(nproc)
```

Run with your custom learner:

```bash
./your_fuzz_target \
    -seeds=./seeds -output=./output \
    -threads=4 --worker-threads=2 --explorer-threads=1 \
    --use-custom-learner
```

## Example: Implementing Epsilon-Greedy

Here is a concrete example — an epsilon-greedy bandit that selects configuration arms:

```cpp
class EpsilonGreedyLearner {
public:
    using Task = TrioFuzzUnifiedLearner::Task;

    explicit EpsilonGreedyLearner(double epsilon = 0.1)
        : epsilon_(epsilon) {
        arms_ = getTrioFuzzConfigArms(true);
        rewards_.resize(arms_.size(), 0.0);
        counts_.resize(arms_.size(), 0);
    }

    Task generateWorkerTask(bool allow_analysis = true) {
        ensureRng();
        Task task{};

        // Epsilon-greedy: explore with probability epsilon, exploit otherwise
        size_t arm_idx;
        if (std::uniform_real_distribution<>(0, 1)(rng_) < epsilon_) {
            // Explore: random arm
            arm_idx = std::uniform_int_distribution<size_t>(0, arms_.size() - 1)(rng_);
        } else {
            // Exploit: best average reward
            arm_idx = 0;
            double best = -1.0;
            for (size_t i = 0; i < arms_.size(); ++i) {
                double avg = counts_[i] > 0 ? rewards_[i] / counts_[i] : 0.5;
                if (avg > best) { best = avg; arm_idx = i; }
            }
        }

        const auto& arm = arms_[arm_idx];
        task.config_arm = arm_idx;
        task.power_schedule = arm.power_schedule;
        task.use_mopt = arm.use_mopt;
        task.splice_enabled = arm.splice_enabled;
        task.use_analysis = arm.use_analysis;
        task.stack_size = 1UL << (1 + std::uniform_int_distribution<uint32_t>(0, 3)(rng_));

        size_t num_ops = task.use_mopt ? 19 : 35;
        std::uniform_int_distribution<size_t> op_dist(0, num_ops - 1);
        task.operator_sequence.resize(task.stack_size);
        for (auto& op : task.operator_sequence) op = op_dist(rng_);

        return task;
    }

    Task generateExplorerTask() {
        auto task = generateWorkerTask();
        task.is_exploration = true;
        return task;
    }

    void processResult(const Task& task, bool found_new_coverage) {
        size_t arm = task.config_arm;
        if (arm >= arms_.size()) return;
        counts_[arm]++;
        rewards_[arm] += found_new_coverage ? 1.0 : 0.0;
    }

private:
    double epsilon_;
    std::vector<TrioFuzzConfigArm> arms_;
    std::vector<double> rewards_;
    std::vector<size_t> counts_;
    // ... rng (same as above) ...
};
```

## Example: Implementing UCB1

```cpp
class UCB1Learner {
public:
    using Task = TrioFuzzUnifiedLearner::Task;

    explicit UCB1Learner(double c = 1.41)
        : c_(c) {
        arms_ = getTrioFuzzConfigArms(true);
        rewards_.resize(arms_.size(), 0.0);
        counts_.resize(arms_.size(), 0);
    }

    Task generateWorkerTask(bool allow_analysis = true) {
        ensureRng();
        Task task{};
        total_pulls_++;

        // UCB1: argmax( avg_reward + c * sqrt(ln(N) / n_i) )
        size_t arm_idx = 0;
        double best_ucb = -1.0;
        for (size_t i = 0; i < arms_.size(); ++i) {
            if (!allow_analysis && arms_[i].use_analysis) continue;
            if (counts_[i] == 0) { arm_idx = i; break; }  // Explore untried arms
            double avg = rewards_[i] / counts_[i];
            double bonus = c_ * std::sqrt(std::log(total_pulls_) / counts_[i]);
            if (avg + bonus > best_ucb) { best_ucb = avg + bonus; arm_idx = i; }
        }

        const auto& arm = arms_[arm_idx];
        task.config_arm = arm_idx;
        task.power_schedule = arm.power_schedule;
        task.use_mopt = arm.use_mopt;
        task.splice_enabled = arm.splice_enabled;
        task.use_analysis = arm.use_analysis;
        task.stack_size = 1UL << (1 + std::uniform_int_distribution<uint32_t>(0, 3)(rng_));

        size_t num_ops = task.use_mopt ? 19 : 35;
        std::uniform_int_distribution<size_t> op_dist(0, num_ops - 1);
        task.operator_sequence.resize(task.stack_size);
        for (auto& op : task.operator_sequence) op = op_dist(rng_);

        return task;
    }

    Task generateExplorerTask() {
        auto task = generateWorkerTask();
        task.is_exploration = true;
        return task;
    }

    void processResult(const Task& task, bool found_new_coverage) {
        size_t arm = task.config_arm;
        if (arm >= arms_.size()) return;
        counts_[arm]++;
        rewards_[arm] += found_new_coverage ? 1.0 : 0.0;
    }

private:
    double c_;
    size_t total_pulls_ = 0;
    std::vector<TrioFuzzConfigArm> arms_;
    std::vector<double> rewards_;
    std::vector<size_t> counts_;
    // ... rng ...
};
```

## Design Notes

### What generateWorkerTask() Controls

The Task fields give you control over the full mutation strategy:

| Field | Controls | Impact |
|---|---|---|
| `power_schedule` | Seed selection strategy | Which seeds get more energy |
| `use_mopt` | Operator set | MOpt (19 ops) vs Havoc (35 ops) |
| `splice_enabled` | Splice operator | Whether cross-over with other seeds is used |
| `operator_sequence` | Mutation operators + order | The exact sequence of mutations applied |
| `stack_size` | Mutation depth | How many operators are stacked per execution |
| `use_analysis` | Expensive analysis | CmpLog, Redqueen, dictionary learning |

### What processResult() Receives

The feedback signal is intentionally minimal: a single boolean `found_new_coverage`. This is because:

1. **It is the ground truth** — new edge coverage is the objective that all fuzzing strategies optimize for.
2. **It avoids information leakage** — giving the learner raw coverage maps would couple it to the coverage representation.
3. **It is fast** — no serialization or copying of coverage bitmaps.

If your algorithm needs richer feedback (e.g., execution time, crash status), you can extend the Task struct or pass additional context through the scheduler loop in `schedulerThreadTrioFuzz()`.

### Thread Safety

- `generateWorkerTask()` and `processResult()` are **only called from the scheduler thread** — they do not need to be thread-safe.
- `generateExplorerTask()` is called from explorer threads — if your learner shares state between worker and explorer generation, protect shared data with a mutex.

### The Three Layers are Optional

TrioFuzz's default learner (`TrioFuzzUnifiedLearner`) uses three coordinated layers, but your custom learner can use any structure:

- A single bandit (like the epsilon-greedy example above)
- A two-level hierarchy (e.g., arm selection + operator sequencing)
- A neural network policy
- A genetic algorithm over configurations
- A rule-based system with no learning at all (useful as a baseline)

The only requirement is implementing `generateWorkerTask()` → `Task` and `processResult(Task, bool)`.
